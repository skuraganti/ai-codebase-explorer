# Upstream work and authorship

Contour uses maintained Python/FastAPI/SQLite, stdlib ast and the official TypeScript6.0.3 compiler API for source parsing; Cytoscape.js renders module graphs. Dependencies are recorded in uv.lock and hash-pinned requirements.lock. Python and Node24 image bases are digest-pinned. TypeScript6.0.3 (Microsoft and contributors, Apache-2.0) is vendored with LICENSE and third-party notices, exact integrity/hash manifest and reproducible acquisition script. Exact browser library and upstream source licenses/notices are retained.

The analyzed Flask and Zod code is clearly attributed data. Contour does not present that code as original portfolio implementation. No upstream application was copied wholesale. The interface, static source indexing, reverse impact paths, bounded source explanation protocol and verification scripts are the portfolio implementation. The host bridge reuses the audited local pattern developed in Folio; this project has its own files, process, IPC directory, control ledger, database, dependencies and containers. There are no runtime imports from another portfolio project.

Independent verification and subsequent corrections are recorded in the verification reports. No fabricated development history, endorsements or general benchmark results.

Source and license references are in DATA_SOURCES.md. The public source and Pages release retain actual dates and upstream credits. Container images remain local.
