# Decisions and experiments

Actual development: 2026-10-16.

- **Source-only inspection:** Running arbitrary downloaded repository code is unnecessary for the chosen user workflow. Use Python AST, the official TypeScript compiler API and exact snapshots; no repository build/test/install commands. Runtime behavior is an explicit unknown.
- **Two contrasting real libraries:** Flask dispatch/package layers plus Zod validation/type re-exports provide useful architecture questions with 66 bounded files. Rich/Ink and Starlette/Zod were compared. Preserve source licenses and notices; original authorship remains visible.
- **Module graph and reverse BFS:** An honest import graph with source lines is more defensible than a guessed cross-language call graph. A hop bound limits exploration. Type-only imports are a user-visible filter rather than silently dropped evidence.
- **SQLite and plain browser UI:** This volume needs neither a graph server nor a vector service. Cytoscape.js is an attributed MIT graph-rendering component; code selection, evidence paths and UI are original. All browser assets are local.
- **Fixed public source model boundary:** Reuse the approved cookllm CLI connection with no model tools and an independent host allowlist. The container receives neither credentials nor a general host execution endpoint. No new provider/route/billing arrangement.
- **Frozen benchmark:** Compare symbol-aware name search to a literal source-line baseline with identical queries/repo scope. Four development/eight held-out tasks are not a claim of general retrieval superiority. Static graph checks and live explanation checks have distinct protocols.
- **Observed first-run failures:** The first bounded Claude implementation run exhausted45turns before a complete suite. Focused independent review found an unquoted SQL keyword, package-prefix loss, type-only and nested declaration errors, reversed deeper impact paths and queue durability/validation problems. These findings were supplied to a separate correction milestone; acceptance awaits independently observed fixes.
- **No hidden reuse:** The user allowed efficient reuse. Relevant public libraries and source examples are credited with licenses; no fabricated provenance or authorship. The public release uses actual development and publication dates.

- **Observed parser failure and correction:** Real Zod files caused a native exit139 with tree-sitter0.26/Python3.14 and valid modern syntax diagnostics with grammar0.23.2. Replaced that path with the official TypeScript6.0.3 JS compiler API, which parses all42selectedTSfiles with0diagnostics. TypeScript7.0.2's npm metadata has no legacy JS main; the official Compiler API reference describes6.0andearlier. The pinned6.0.3 API is used for parsing only; no CompilerHost, emit, module imports or source execution. Fixed Node process gets no provider credentials, shell or arbitrary executable.
- **Generic final corrections:** Root completed path containment with descriptor walking, strict public provenance, current revision/hash citation checks, queue commit ordering, pending/result recovery, exact newline citation endpoints, parser-version reindexing, and async UI response guards. Existing completed responses now survive restart. Two45turn worker attempts were bounded; root changed approach and completed acceptance directly.
- **Observed live limits:** Four frozen real calls yielded two unqualified passes, one qualified explanation (citation incompleteness) and one failed-closed quote validation. No automatic retry, heldout-specific tuning or weakened validation. An additional browser repeat is tracked separately.
